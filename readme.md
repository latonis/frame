# frame

frame is a small project of mine that uses a raspberry pi and an e-ink display to display photos that bring me joy. I want to add an sd card reader to the project and have a few images. Eventually, this will be turned into a keychain for me to carry with me wherever I go.

## Items currently used
- raspberry pi pico 
- WeAct Studio 1.54in e-ink display
- button (2)
